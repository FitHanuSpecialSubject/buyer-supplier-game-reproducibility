# Buyer-Supplier Game Reproducibility Package

This repository contains the reproducibility package for the buyer-supplier game optimization experiment.

## Contents

- `data/`: fixed synthetic input dataset used in the experiment.
- `src/`: source code used for payoff calculation and optimization.
- `config/`: algorithm configuration used in the experiment.
- `results/`: output results generated by the application.
- `verification/`: worked example for manual payoff calculation verification.

## Dataset

The input dataset is synthetic and was generated under controlled parameter ranges. The final dataset was fixed before the optimization process and used consistently across all experimental runs.

The complete input dataset is provided in:

- `data/final_input_dataset.xlsx`
- `data/final_input_dataset.csv`

## Algorithm Configuration

The algorithm parameters used in the experiment are provided in:

- `config/algorithm_config.txt`

## Reproduction Steps

To reproduce the reported results:

1. Open the fixed input dataset in `data/final_input_dataset.xlsx`.
2. Import the input file into the application.
3. Use the algorithm parameters provided in `config/algorithm_config.txt`.
4. Run the optimization algorithm.
5. Compare the generated output with the files provided in `results/`.

## Verification

A representative worked example for manual payoff calculation is provided in:

- `verification/worked_example_calculation.xlsx`

This file demonstrates how the payoff value is calculated from the input values using the matching and aggregation formulas.

## Note

Due to space limitations, the full dataset is not presented in the main manuscript. This repository allows independent verification and reproduction of the reported computational results.
